# max<TAB>pattern, for font-list-probe.c on the font-list path.
# Not here: an XLFD naming a size, or with a size wildcard, that reaches a
# bitmap XLFD before max-names runs out. Xorg's bitmap scaler adds scaled
# and -0-0- names for those (and lists an exact one twice); yserver does
# not scale bitmap fonts.
# CDE: dtwm, dtterm and dtpad probe their -dt-interface aliases one name at a time.

# yserver does not scale bitmap fonts.
